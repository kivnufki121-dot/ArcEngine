# BLACKSITE: RAPTOR — прототип 01

Отдельная игра в папке `survival-horror/`, использующая Babylon.js из ArcEngine. Исходный ArcEngine не изменён.

## Запуск на Windows
1. Распакуйте ZIP целиком.
2. Запустите `run.bat` в корне архива (нужен Node.js LTS).
3. Откройте `http://localhost:8080/survival-horror/` (если сервер выбрал другой порт, замените 8080).
4. Нажмите «Начать эвакуацию». Для управления мышью нажмите в игре.

## Управление
- WASD — ходьба, мышь — камера
- Shift — бег, Ctrl — красться
- E — взаимодействие
- Xbox: левый стик — ходьба, правый — обзор, A — взаимодействие, B — красться, L3 — бег

## Цель
Найти три светящиеся энергетические ячейки и активировать шлюз на северной стене. Избегать динозавра.

## Текущие ограничения
- Геометрический прототип, без импортированных моделей и сюжетных сцен.
- Простое преследование без навигационной сетки.
- Пока нет сохранений, инвентаря и боевой системы.
- Проверка запуска в браузере и на геймпаде пользователем ещё не выполнена.
