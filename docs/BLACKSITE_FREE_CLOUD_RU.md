# Бесплатная облачная обработка для BLACKSITE: RAPTOR

## Уже работает

В ветке `game/blacksite-raptor-prototype` настроен [BLACKSITE free cloud Blender](../.github/workflows/blacksite-cloud-blender.yml): GitHub Actions (`ubuntu-24.04`, Blender без интерфейса). Стандартные GitHub-hosted runners бесплатны для **публичных** репозиториев. Это не постоянно работающий VPS и не GPU-сервер.

- Код обработчика: [cloud/blender/runner.py](../cloud/blender/runner.py)
- Задание: [cloud/blender/job.json](../cloud/blender/job.json)
- Выполненные задания: https://github.com/kivnufki121-dot/ArcEngine/actions
- Артефакт каждого запуска: **blacksite-blender-results**, срок хранения 7 дней.
- Поддерживаемые операции: `smoke_test`, `inspect_glb`, `prepare_uv`.
- При изменении `cloud/blender/job.json` задача запускается автоматически в GitHub Actions. Можно дать задание в чате — ассистент, при наличии GitHub-коннектора, изменит JSON и прочитает статус.
- `prepare_uv` читает GLB внутри репозитория, строит недостающие UV в Blender и создаёт `character_uv.blend` / `character_uv.glb` как **отдельные** файлы артефакта. Исходник не изменяется.
- Входные GLB должны находиться внутри репозитория. GitHub Actions не может читать файлы напрямую с рабочего стола пользователя и не видит файлы ChatGPT, пока они не размещены в доступном хранилище.
- Скрипт не выполняет произвольные переданные команды; разрешён только небольшой набор операций. Изменения репозитория не должны запускать непроверенный код из сторонних ссылок.
- Ограничения использования GitHub Actions и политика допустимых задач действуют даже для публичных репозиториев.

## Бесплатный GPU для тяжёлых нейросетей — отдельная задача

**Kaggle Notebooks:** бесплатные GPU Tesla P100 с квотой около 30 часов в неделю (может меняться), но временные интерактивные сеансы и очереди. GPU-задачи на Kaggle **не подключены** к этому чату. Для управляемого запуска нужен аккаунт и отдельный безопасный авторизованный механизм. Не сохранять секретные Kaggle API-токены в публичном GitHub-репозитории.

**Google Colab Free:** бесплатный GPU бывает доступен, но не гарантирован; сеансы и лимиты меняются. Не применять как постоянный сервер, не обходить правила Colab.

**Hugging Face ZeroGPU:** бесплатный динамический GPU в Gradio Spaces; для бесплатных пользователей доступно до 2 собственных ZeroGPU Spaces при выполнении условий платформы, но дневная квота около 5 минут. Это не полноценный постоянно доступный сервер ComfyUI; тяжёлые задачи могут не поместиться.

Наличие публичного репозитория или запуска GPU-сервиса само по себе не предоставляет ассистенту права доступа к чужому аккаунту или интерактивной сессии. Подключения и действия требуют явного разрешения владельца аккаунта.

## Что сказать ассистенту

- «Проверь структуру `assets/models/character.glb` через бесплатный Blender в GitHub».
- «Сделай UV-развёртку модельки из репозитория и дай результат».
- «Проверь текущую облачную задачу».
- «Подготовь задачу для скелета и анимации» — для рига понадобится добавить поддержку в cloud/blender/runner.py и исходный GLB; эта операция пока не реализована.
