# BLACKSITE: RAPTOR — инструменты для катсцен и диагностики

Проверено по README трёх upstream-репозиториев 2026-10-26. Этот документ **не устанавливает** инструменты и не изменяет сборку игры.

## Основной игровой конвейер

1. **Геометрия героини** — Blender / AssetFurnace / Charakuru: подготовить человекоподобную модель по референсу, проверить ориентацию и T-/A-позу. Не смешивать генерацию модели с установкой ComfyUI.
2. **UV и текстуры** — ComfyUI + **один** UltraTex-пакет: для Windows вначале проверить UltraTex Modular. Не устанавливать параллельно оба конфликтующих набора UltraTex. Сначала тест 1024/2048, затем 4K; 8K только при подтверждённом запасе памяти. Проверять права на коммерческое использование весов.
3. **Риг и анимации** — Blender + Charakuru/AssetFurnace; для готового скелета Motion2MixamoRig или UniMate. Последние требуют отдельных моделей/зависимостей. T-поза без скелета — не готовая игровая анимация.
4. **Катсцены** — [kijai/ComfyUI-WanVideoWrapper](https://github.com/kijai/ComfyUI-WanVideoWrapper). Использовать вне игрового цикла для коротких предрендеренных видео: крушение вертолёта, сообщения Марлоу на экранах, титры финала. Анимированные кадры должны сохранять дизайн героини; в сам Babylon.js WanVideoWrapper не подключать.
5. **ComfyUI-Manager** — [Comfy-Org/ComfyUI-Manager](https://github.com/Comfy-Org/ComfyUI-Manager). Устанавливает/обновляет пользовательские узлы. Перед ручной установкой проверить, что Manager уже включён в существующий ComfyUI-Easy-Install; избежать дубликатов. Перед обновлениями сохранять snapshot.
6. **Диагностика готового EXE** — [morluto/rea](https://github.com/morluto/rea). REA помогает разбирать Electron/JS-модули, IPC и работу приложения; не является движком, видеогенератором или риггером. Анализировать только собственные сборки/разрешённые программы. Это отдельный локальный MCP-инструмент: подключение нужно выполнить к совместимому агенту (например, Codex), если он установлен.

## Практический порядок для Windows 11 + RTX 5060 Ti 16 GB

**ComfyUI:**
- Установить в короткий путь без кириллицы, например `D:\AI\ComfyUI`.
- ComfyUI-Easy-Install: https://github.com/Tavris1/ComfyUI-Easy-Install
- Если ComfyUI-Manager уже присутствует, не клонировать его второй раз. При ручной установке из ComfyUI/custom_nodes: `git clone https://github.com/Comfy-Org/ComfyUI-Manager comfyui-manager` (перед этим проверить установленную версию).
- WanVideoWrapper по необходимости — из ComfyUI/custom_nodes: `git clone https://github.com/kijai/ComfyUI-WanVideoWrapper`. Ставить зависимости **Python-интерпретатором ComfyUI**, а не глобальным Python 3.15: `python_embeded\python.exe -m pip install -r ComfyUI\custom_nodes\ComfyUI-WanVideoWrapper\requirements.txt` (запуск из корня portable-сборки).
- Модели WanVideoWrapper скачиваются отдельно; README автора перечисляет text encoder, CLIP vision, diffusion model и VAE. Для 16 GB VRAM сначала выбирать облегчённые конфигурации и offload/block swap; совместимость конкретной модели проверить перед загрузкой весов.
- WanVideoWrapper — экспериментальный wrapper. Автор рекомендует пользоваться нативными узлами ComfyUI, если нужные функции там уже есть.

**REA / диагностика:**
- README: https://github.com/morluto/rea
- При наличии совместимого локального агента: `npx rea-agents setup`, прочитать предложенные изменения, выбрать агента, подтвердить и перезапустить. Для простого анализа JavaScript/Electron Ghidra не обязателен.
- При диагностике BLACKSITE проверять: main/preload, путь к HTML и JS, bundled assets GLB, логи загрузки, ошибки рендера, версию build stamp. Для текущих ошибок видимости дополнительно нужен внутриигровой диагностический лог — REA не заменяет измерения состояния камеры и сцены в Babylon.js.

## Ограничения и критерии проверки

- **Видео**: убедиться, что результат WanVideo содержит персонажей согласованного вида; фиксировать исходные промпты, исходный референс, модель и seed.
- **Модели**: GLB реально открывается, скелет и skin weights существуют, материалы и UV не повреждены, idle/walk/run воспроизводятся.
- **Сборка**: EXE запускается в новой папке, без старого кэша; основные GLB загружаются локально; ошибки записываются в TXT.
- Никакие сторонние программы и нейросетевые веса пока **не установлены через этот документ**. Для загрузки весов возможны десятки гигабайт и отдельные лицензии.
